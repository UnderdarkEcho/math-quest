# Math Quest for homeschool families

Math Quest is free. There is no account, no email, and no cloud login.

Progress lives on **this iPad or phone**. Treat the Home Screen icon as the app.

## Add to Home Screen

Safari can forget website data after about a week if you only open Math Quest in a regular tab.

1. Open Math Quest in Safari (not a Private tab, not a preview inside Messages).
2. Tap **Share** (the box with the arrow).
3. Tap **Add to Home Screen**.
4. Open Math Quest from **that icon** every time.

On Android: browser menu → **Add to Home screen** / **Install app**.

A Classroom or Messages preview is not the app. Use the same Home Screen icon.

## Several children on one iPad

The first screen is **Who’s playing?** Add another child there. Each child has their own stars, courses, Snap, and tables.

This device can keep up to 12 children. Duplicate first names are fine.

## Keep a spare copy

Math Quest cannot recover a wiped Safari by itself.

On **Profile**:

- **Save backup** downloads a JSON file.
- **Copy backup code** puts the same data on the clipboard.
- **Restore backup** adds those children or replaces everyone on this device.

Save a backup before you:

- clear Safari / website data
- sell or reset the device
- switch browsers (Safari and Chrome on iPhone do not share progress)

## Private tabs

Private / Incognito tabs forget Math Quest when they close. The yellow or red banner means “this session will not last.” Use the Home Screen icon instead.
